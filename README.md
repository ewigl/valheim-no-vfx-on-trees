# No VFX On Trees

Removes some visual effects from trees when they are hit or destroyed.

## Configuration

The plugin provides configuration options to disable specific visual effects on trees:

- **Destruction**
  - `DisableSmoke`: Remove smoke effects when trees are destroyed.
- **Hit**
  - `DisableSmoke`: Remove smoke effects when trees are hit.
  - `DisableSawdust`: Remove sawdust effects when trees are hit. (Will also remove smoke effects cause it's part of the same VFX).
